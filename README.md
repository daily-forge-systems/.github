# .github

Special organization-wide repository for `daily-forge-systems`. It provides:

- **`profile/README.md`** — the content shown on the [organization's public profile page](https://github.com/daily-forge-systems).
- **`.github/ISSUE_TEMPLATE/`**, **`.github/pull_request_template.md`** — default community health files. GitHub uses these for any repository the organization owns that does not define its own copy of that file, regardless of whether that repository is public or private, as long as this `.github` repository stays public. Every product repository here does carry its own copies today, so the defaults are in practice a fallback rather than the live forms.
- **`.github/CODEOWNERS`** — listed here with the files above until 2026-09-09, which was wrong. `CODEOWNERS` is not among the file types GitHub inherits org-wide, so each repository needs its own.

This repository is public so the profile page renders; every product/package repository in the organization stays private.
